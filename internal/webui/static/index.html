连接设置

SSH 私钥（.pem）
选择用于登录远程服务器的私钥文件（无密码的 .pem / id_rsa）
远程主机 IP / 域名
要访问本机的远程服务器地址
用户名
远程服务器的 SSH 登录用户名
远程端口
远程服务器上映射到的端口（远程访问 localhost:此端口）
本地端口
本机要暴露出去的服务端口（默认 = 代理端口）
随 ApiCluster 启动
开启后，ApiCluster 启动时会自动建立隧道（配合「设置 → 开机自启」实现无人值守）
断开自动重连
关闭时：不只是断开不重连，启动那一刻第一次连接失败也不会再试， 界面会停在「已断开」并显示原因，需要你手动点「启动」
